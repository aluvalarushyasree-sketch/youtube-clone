# YouTube Clone

## Description
A frontend clone of the YouTube homepage built using HTML and CSS. The project focuses on layout design, responsive structure, Flexbox, and CSS Grid.

## Features
- YouTube-inspired layout
- Navigation bar
- Sidebar
- Video grid section
- Responsive design

## Technologies Used
- HTML
- CSS

## Project Structure
youtube-clone/
├── index.html
└── style.css

## How to Run
1. Download the project.
2. Open index.html in a browser.

## Learning Outcomes
- HTML Structure
- CSS Styling
- Flexbox
- CSS Grid
- Responsive Design
